What is Rekaluna?

Rekaluna is an open-source browser workspace built specifically for print shop operators. It is a lightweight collection of practical tools that help people working behind a print counter complete their daily tasks faster.

Rekaluna is not a printing marketplace, not an online printing service, not a POS system, and not an admin dashboard. It is a personal productivity workspace — designed to be the tab you open in the morning and close at night.

Motivation

Print operators juggle image printing, price calculations, driver hunting, and customer changes all day — often with generic tools, calculator apps, and messy file explorers. Rekaluna was built by observing real counters: paste an image and print, tap prices instead of typing, find the right driver without hunting shady download sites.

Philosophy

  • Simple — every feature must be immediately understandable.
  • Fast — minimize clicks. Tap, not type.
  • Practical — solve real workflow problems only.
  • Lightweight — no bloat, no frameworks, fast load.
  • Local-first — data stays in your browser (localStorage). No accounts, no tracking.
  • Open-source — transparent, accessible, community-friendly (MIT).

Features

  • Quick Print — Ctrl+V paste, drag & drop, preview, rotate, paper sizes (A4/F4/Letter/Legal), portrait/landscape, margin, fit/fill, window.print().
  • Price Desk — cashier-fast calculator with quick-money buttons, editable service prices, quantity controls, auto Indonesian formatting, undo/clear, local persistence, recent calculations.
  • Resources — curated drivers (Epson, Canon, Brother, HP) and apps (Lightshot, Acrobat Reader, SumatraPDF, 7-Zip, Everything, Notepad++) linking only to official sources.
  • Command Palette — Ctrl+K to jump anywhere. Keyboard shortcuts throughout.

Tech

HTML5 • CSS3 • Vanilla JavaScript (ES6+) • Inter • Font Awesome • No frameworks, no Tailwind, no Bootstrap. Cleanly split into style.css, components.css, responsive.css and modules app.js, calculator.js, print.js, storage.js, ui.js.
